browser ──► caddy:443 (app.example.com, /app)

   │                     tenant "example"

   │                     resource "/app"
   │  2xx ────────────► nginx serves this file
  4xx ────────────────► caddy /login

One janux instance, two public hostnames. Caddy fronts app.example.com (this gated app) and auth.example.com (the IdP/admin/discovery host) onto the same auth service.

Host-only cookie caveat: because janux's session cookie has no Domain attribute, a session established on auth.example.com is NOT sent to app.example.com — that's why the magic link targets app.example.com/login so the /app demo is self-contained. See ../README.md §"split-hosts".
